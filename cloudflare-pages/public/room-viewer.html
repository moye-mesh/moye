MOYE Room Viewer

Read-only room view in the browser. Public rooms can be fetched live from a node. For a private room, an authenticated member (Rooms UI, CLI, MCP, or SDK) fetches the messages first; paste that JSON here and this page decrypts it locally — the secret never leaves your browser.

Option A — Public room (fetches live)

Option B — Private room (paste fetched JSON)

Fetch first with an authenticated client, e.g.: node cli.js room-messages <room_id>

Full docs: moye.ai/docs · this page's source has no external dependencies and never phones home except the one optional live fetch in Option A.
